# 文件格式检查功能

## 功能说明

在资源导入的批量上传过程中，系统现在会自动检查文件格式：

- **ULPK Key**: 必须是 `.dat` 格式文件
- **HDCP Key**: 必须是 `.bin` 格式文件

## 工作原理

### 批量上传检查
1. 选择Key类型后，系统确定期望的文件格式
2. 遍历文件夹中的所有文件
3. 检查每个文件的扩展名是否符合要求
4. 跳过不符合格式的文件，并记录跳过数量
5. 只上传符合格式的文件

### 单个文件上传检查
1. 选择文件后，检查文件扩展名
2. 如果不符合格式，显示错误提示并阻止上传
3. 符合格式的文件正常上传

## 用户体验

### 批量上传结果显示
```
批量导入完成：
✅ 成功上传: X 个文件
⚠️  跳过格式不符: Y 个文件
📁 总文件数: Z 个
```

### 单个文件格式错误提示
```
文件格式不正确！

Key 类型: ULPK 5586F dev
期望格式: *.dat
选择文件: wrong_file.txt

请重新选择正确格式的文件。
```

## 支持的文件格式

| Key 类型 | 文件格式 | 示例文件名 |
|---------|---------|-----------|
| ULPK | *.dat | ulpk_key.dat, ULPK_DATA.DAT |
| HDCP | *.bin | hdcp_key.bin, HDCP14_KEY.bin |

## 注意事项

- 文件扩展名检查不区分大小写
- 无扩展名的文件会被跳过
- 格式检查在网络检查之后进行
- 只有符合格式的文件才会尝试上传到MinIO
