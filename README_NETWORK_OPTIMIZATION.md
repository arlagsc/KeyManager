# Key/MAC 烧录管理系统 - 网络优化版本

## 优化内容

### 网络连接检查
- **启动时检查**: 程序启动时自动检查MinIO服务器连接状态
- **实时状态显示**: 在主窗口底部显示网络连接状态
- **手动检查**: 在"资源导入"标签页中提供"检查连接"按钮
- **操作前验证**: 在所有网络操作前检查连接状态

### 错误提示优化
- **明确的错误信息**: 当网络不通时，显示具体的错误提示
- **操作阻止**: 网络不通时阻止相关操作，避免无提示失败
- **用户友好**: 使用对话框显示错误信息，便于用户理解

### 网络检查功能
- 新增 `MinioWarehouse.check_network_connection()` 方法
- 通过socket连接测试MinIO服务器可达性
- 5秒超时，避免长时间等待

## 使用说明

1. **启动程序**: 程序启动时会自动检查网络连接
2. **查看状态**: 主窗口底部显示网络状态
3. **手动检查**: 点击"资源导入"标签页中的"检查连接"按钮
4. **网络操作**: 所有需要网络的操作都会先检查连接状态

## 网络故障处理

当遇到网络问题时：
1. 检查网络连接是否正常
2. 确认MinIO服务器是否运行
3. 验证服务器地址和端口配置
4. 使用"检查连接"按钮重新验证

## 配置文件

网络配置在 `config.json` 中：
```json
{
  "minio": {
    "endpoint": "172.16.9.28:9000",
    "access_key": "admin",
    "secret_key": "12345678",
    "bucket": "warehouse"
  }
}
```
