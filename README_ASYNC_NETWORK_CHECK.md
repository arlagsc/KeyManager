# 网络检查异步化修复

## 问题描述

在之前的版本中，网络连接检查是在 `MainWindow.__init__()` 方法中同步进行的。如果网络连接有问题或者服务器响应慢，程序会在UI显示之前卡住很长时间，用户看不到任何界面。

## 解决方案

### 异步网络检查
1. **UI优先显示**: 先创建完整的UI界面，让用户能看到程序已启动
2. **异步检查**: 在UI显示后100毫秒，使用 `QTimer.singleShot()` 启动异步网络检查
3. **状态指示**: 初始状态显示"正在检查连接..."，检查完成后更新为实际状态

### 超时优化
- 将网络连接检查的超时时间从5秒缩短到2秒
- 减少用户等待时间

### 错误处理增强
- 网络检查过程中如果发生异常，会显示错误提示
- 确保程序在任何情况下都能正常启动

## 工作流程

```
程序启动 → 创建UI界面 → 显示"正在检查连接..." → 100ms后异步检查网络 → 更新状态显示
```

## 代码变更

### admin_client.py
- 将网络检查从 `__init__` 移到异步方法 `_async_check_network`
- 添加初始状态处理（None表示正在检查）
- 在程序启动时使用 `QTimer.singleShot` 延迟执行网络检查

### minio_db.py
- 将 `check_network_connection` 的超时时间从5秒改为2秒
